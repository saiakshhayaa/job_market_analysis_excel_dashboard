# 📊 Job Market Analysis Excel Dashboard

## 📌 Overview
This project is an Excel-based Job Market Analysis Dashboard built to analyze job market trends, salary insights, work modes, and skill demand in data-related roles. The dashboard transforms raw job market data into meaningful insights using Excel analytics tools.

---

## 🎯 Objective
The objective of this project is to analyze:
- Salary trends across job roles and countries
- Job demand across platforms
- Remote vs onsite work patterns
- Skill demand and salary relationship
- Weekly and monthly job posting trends

---

## 🧹 Data Cleaning & Preparation
- Cleaned and transformed data using Power Query
- Performed data formatting and unpivoting for skill analysis
- Created relationships using Data Model
- Built calculations using explicit measures
- Structured data for dashboard reporting

---

## 📊 KPIs
- Total Jobs
- Median Salary
- Remote Work Percentage
- Top Platform
- Platform Job Count

---

## 📈 Dashboard Features

### Main Dashboard
- Salary by Country
- Salary by Job Title
- Work Mode Analysis
- Monthly Job Posting Trend
- Salary by Job Schedule

### Interactive Filters
- Job Title
- Country
- Work Mode
- Platform

---

## 📑 Report Pages
- Regional Analysis (US vs Non-US Salary Comparison)
- Salary Comparison

- Weekly Job Analysis
